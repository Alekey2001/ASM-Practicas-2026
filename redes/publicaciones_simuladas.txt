## 📐 1. Arquitectura de Funciones: Motores de Búsqueda y Crawling

Para auditar la información expuesta en fuentes abiertas, es fundamental comprender cómo los motores de búsqueda recopilan y almacenan los activos web.

```text
       [ INTERNET ]
            │
            ▼
     ┌─────────────┐
     │   Crawler   │ ──> (Descubre: Palabras clave, URLs, archivos, enlaces)
     └─────────────┘
            │
            ▼
     ┌─────────────┐
     │    Index    │ ──> (Almacena y organiza las ubicaciones encontradas)
     └─────────────┘
            │
            ▼
  ┌──────────────────┐
  │ Search Engine UI │ ──> (Procesa consultas del usuario sobre el índice)
  └──────────────────┘
Crawler (Spider/Araña): Programa automatizado encargado de rastrear activamente páginas web, recopilar metadatos y seguir enlaces salientes hacia otros dominios.Index (Índice): Base de datos organizada que registra la colección de recursos descubiertos y sus ubicaciones exactas.Search Engine (Buscador): Interfaz que realiza búsquedas optimizadas directamente sobre el Index, no sobre Internet en tiempo real.Regla Memotécnica: El Crawler descubre, el Index registra y el Search Engine consulta.🛡️ 2. Auditoría de Archivos de Control (robots.txt y sitemaps.xml)Las configuraciones destinadas al SEO (Search Engine Optimisation) suelen convertirse en la primera fuente de información para un auditor de seguridad.A. El archivo robots.txtUbicado en la raíz del servidor web (ej. https://aiaco.local/robots.txt), instruye a los bots sobre qué secciones pueden o no rastrear.HTTPUser-agent: *
Allow: /
Disallow: /admin/
Disallow: /private/
Sitemap: [https://aiaco.local/sitemap.xml](https://aiaco.local/sitemap.xml)
User-agent: Especifica el bot al que se aplica la regla (* = wildcard para todos los crawlers; Bingbot = crawler de Microsoft Bing).Allow / Disallow: Define los permisos de rastreo sobre las rutas del servidor.Implicación de Seguridad (CRÍTICO):robots.txt no es un mecanismo de control de acceso. Marcar una ruta como Disallow: /admin/ no restringe el acceso a usuarios, sino que alerta públicamente a un atacante sobre la existencia de un directorio sensible.B. El archivo sitemap.xmlUn Sitemap funciona como un mapa del sitio (en formato XML) que enumera explícitamente las rutas (routes) y páginas del servidor para optimizar el recorrido del crawler.Plaintext              [ HOME ]

Perspectiva ASM: Actúa similar a una lista de palabras (wordlist) predeterminada. Revela la estructura interna del sitio web sin necesidad de ejecutar herramientas de fuerza bruta de directorios (como Gobuster o ffuf).🔎 3.
